# Customer Churn Dataset - Data Dictionary

This document explains the columns and variables present in the customer churn dataset.

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| **CustomerID** | String | A unique identifier for each customer. |
| **Gender** | String | The gender of the customer (`Male`, `Female`). |
| **Age** | Integer | The age of the customer in years. |
| **TenureMonths** | Integer | The number of months the customer has been subscribed to the service. |
| **SubscriptionType** | String | The type of subscription plan (`Basic`, `Pro`, `Enterprise`). |
| **MonthlyCharges** | Float | The amount charged to the customer on a monthly basis. |
| **TotalCharges** | Float | The total amount charged to the customer over their entire tenure. |
| **ContractType** | String | The duration of the customer's contract (`Month-to-Month`, `One Year`, `Two Year`). |
| **SupportTickets** | Integer | The number of support tickets opened by the customer. |
| **PaymentMethod** | String | The method the customer uses to pay (`Credit Card`, `Debit Card`, `Bank Transfer`, `UPI`). |
| **Churn** | String | Indicates whether the customer has left the service (`Yes`, `No`). |
